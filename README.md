# Telegram Media Archive 5.0 — удобное меню для iPhone

Это **обновление интерфейса действующего архиватора**, а не новый бот и не замена Telegram-аккаунта. Его задача — дать владельцу понятные экраны и кнопки вместо длинных команд и ручного ввода ID.

## Меню владельца

Отправьте управляющему боту `/start` или `/menu` в личной переписке. Он покажет кнопки:

| Кнопка | Что открывает |
| --- | --- |
| 💬 Личные чаты | Переписки личного аккаунта с названиями и статусом. Нажмите на чат, затем подтвердите включение/остановку сохранения. |
| 👥 Группы | Группы, в которых работает бот; статус, включение и остановка через подтверждение. Перед включением бот публикует уведомление участникам. |
| 📚 Архив сообщений | Последние сохранённые тексты, просмотр сообщения и истории изменений. |
| 📷 Фото и видео | Список сохранённых вложений и кнопка «Получить файл», если выдача разрешена настройками сервера. |
| ✉️ Пишут боту | Личные сообщения пользователей непосредственно боту, файлы и список давших согласие. |
| 🗑 Удалённые | Записи, для которых Telegram передал подтверждение удаления; отсутствие пометки не означает, что сообщение не удалялось. |
| 📊 Состояние | Сколько сохранено текстов и медиа, сколько активных групп, свободное место, выдача файлов. |
| ⚙️ Настройки | Просмотр конфигурации без раскрытия токенов; изменение секретных параметров через бота запрещено. |
| ❓ Помощь | Памятка по архивированию и ограничениям Telegram. |

На экранах есть **«Назад»**, **«Главное меню»**, переключение страниц. На кнопках чатов показывается «✅» или «⏸». Включение/остановка требует отдельного подтверждения, ID вручную вводить не нужно. Все управляющие кнопки проверяют Telegram ID владельца на сервере при каждом нажатии; наличие кнопки **само по себе не даёт прав**.

Владелец может продолжать пользоваться существующими командами `/status`, `/private`, `/private_on`, `/private_off`, `/groups`, `/messages`, `/recent`, `/file`, `/deleted`, `/inbox`, `/people`. Полный список: `/commands`.

## Для собеседников, которые пишут боту

Они видят отдельную панель **«✅ Согласен», «⏸ Остановить запись», «🗑 Удалить свой архив», «🔐 Условия хранения»**. До согласия никакие их сообщения не архивируются. Удаление из текущего архива подтверждается отдельным нажатием; резервные копии необходимо удалять отдельно по политике хранения. Доступа к архивам владельца у них нет.

## Сохранение и ограничения

- Используются существующая SQLite-база, Docker volume, `user.session`, `.env` и тот же управляющий бот.
- При обновлении **настройки архивирования и выдачи файлов не переключаются автоматически**. Уже выбранные чаты остаются в прежнем состоянии.
- Новые обычные тексты, доступные фотографии, видео, документы и правки сохраняются только в соответствующих разрешённых чатах или группах. Не обещается восстановление старых сообщений.
- Секретные чаты, одноразовые и защищённые медиа не обходятся. Telegram не гарантирует события удаления.
- Для полноценного получения сообщений в группе боту нужен соответствующий доступ Telegram; участникам должно быть известно об архивировании.
- Для личных переписок вашего аккаунта информируйте собеседника и соблюдайте применимые правила хранения личных данных.

## Установка на прежний Hetzner

Скачайте `TelegramMediaArchive_v5_EasyUI_Mac.zip`, распакуйте на MacBook и запустите **«Установить удобное меню v5.command»**. Используется ваш существующий SSH-ключ `~/.ssh/rent_sender_ed25519` и сервер `monitor@2.29.13.125` (IP уже внесён в установщик). Никаких секретов отправлять в ChatGPT не нужно.

Установщик:
1. Перед остановкой контейнера запускает **77 локальных тестов**, собирает образ без подключения к Telegram и проверяет импорт.
2. Создаёт копию действующей SQLite и проверяет миграцию данных на копии.
3. Проверяет свободное место и останавливает только `telegram-media-archive` / `archive`.
4. Создаёт закрытую резервную копию действующего кода, конфигурации и тома с Telegram-сессией.
5. Обновляет код, пересобирает контейнер, проверяет сообщения `READY` и работоспособность процесса; при ошибке **пытается** вернуть код прошлого выпуска.

**Действующие Telegram Monitor и RentWeeklySender не изменяются установщиком.** При неудаче не запускайте установщик повторно, пока не изучен журнал ошибок. Резервная копия содержит секреты и личные данные; храните её защищённо.

Успешный финальный маркер: `TELEGRAM_MEDIA_ARCHIVE_V5_EASY_UI_INSTALLED_AND_VERIFIED`.
