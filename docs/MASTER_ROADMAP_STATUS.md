## Правила

- Не менять статус на «Проверено» без ссылки на конкретный коммит, тесты и протокол.
- Для работ, требующих Telegram-сессий, Hetzner, закрытых исходников, платежей или согласий участников, фиксировать «Заблокировано» до безопасной проверки.
- Публичный репозиторий не должен содержать токены, приватные переписки, ключи и пользовательские данные.
- Приоритет исполнения: P0 (TMA-001—012, TMA-035—041), затем функции P1, P2, P3 по зависимостям.
